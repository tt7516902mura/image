# Website Image Extractor v3

URLを入力すると、ページ内の画像（SPA・無限スクロール・複数ページ対応）を抽出し、選択してZIP・個別保存・共有ができるツールです。Cloudflare Workers と Browser Rendering で動作します。

## セットアップ
1. `npm install`
2. `npx wrangler login`
3. 動作確認：`npm run dev`（Browser Renderingはローカル実行不可のためリモート実行）
4. 公開：`npm run deploy`
5. アクセス制御（公開時は必須級）
   - 推奨：Cloudflare Access でアプリ全体を保護
   - 簡易：`npx wrangler secret put ACCESS_TOKEN` を設定すると、/api/* がトークン必須になります（画面の「複数URL・アクセス設定」に入力）
   - 任意：wrangler.toml の Rate Limiting バインディング（コメント参照）

Browser Rendering の利用条件・料金・同時実行数はCloudflareの最新の案内を確認してください。

## 構成
- `public/index.html`：UI（抽出・選択・ZIP・履歴）
- `public/_headers`：CSPなどのセキュリティヘッダ
- `worker.js`：API（/api/page, /api/img, /api/scan）
- `tests/test.mjs`：テスト（`npm test`）

## v3の主な変更
- **メモリ**：読み込み時は縮小サムネイルのみ保持し、元画像は破棄。拡大表示・保存時に必要な画像だけ再取得し、ZIPは取得しながら書き出し（全展開しない）
- **セキュリティ**：Origin検証、アクセストークン、IP別レート制限、同時スキャン制限（全体2件・利用者1件）、画像の中身による形式検証（偽装HTML・スクリプト入りSVGを拒否）、ブラウザのポップアップ／新規タブの強制クローズ（検証迂回の防止）、GET以外のサブリクエスト遮断
- **管理**：複数URLの順次処理、URL別・ページ別の絞り込みと処理状況、エラーログ、JSON出力、履歴（保存ボタンを押したときのみ・メタ情報のみ）
- **iOS**：入力16px（自動ズーム防止）、44px以上のタップ領域、共有は「準備→共有を開く」の2段階、ZIPは完成後に「保存／共有」ボタン

## 既知の制限
- レート制限・同時実行数のカウントはIsolate単位で、全拠点で厳密ではありません（厳密にはRate Limitingバインディング／Durable Objectsが必要）
- DNSリバインディングは、ブラウザ側で接続先IPを固定できないため完全には防げません（Workersの外向き通信は自社の内部ネットワークに届かない点で緩和）
- ZIP中に取得エラーが途中で起きた場合は、破損を避けるため全体を中止して破棄します（開始前に読めなかった画像のみ `_failed.txt` に記録）
- ZIPは無圧縮で、4GB・65,000枚が上限
- ZIPのディスク直接書き出しは `showSaveFilePicker` 対応ブラウザ（主にデスクトップChrome・Edge）のみ。iOS Safari等はメモリ上でBlob化します
- ログインが必要なページや認証・アクセス制限の回避は行いません

## 手動テスト手順（実機）
1. 画像の多いSPA、無限スクロールのページ、「次へ」リンクのあるページで抽出
2. 抽出中にキャンセルし、状態とメモリが残らないことを確認
3. 100枚以上を選択してZIP保存。展開して枚数・破損を確認
4. iPhoneで「共有／写真に保存」を2回押し、「画像を保存」で写真アプリに入ることを確認
5. 内部アドレス（`http://169.254.169.254/` など）や `file://` が拒否されることを確認
